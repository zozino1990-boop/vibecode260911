01

HTML · 뼈대

제목, 문단, 이미지, 버튼처럼 페이지에 들어갈 콘텐츠와 의미를 정의합니다.

02

CSS · 스타일

색, 크기, 여백, 배치, 반응형 규칙으로 콘텐츠의 인상과 사용성을 만듭니다.

03

JavaScript · 동작

클릭, 입력, 데이터 변경에 반응해 페이지를 살아 있는 경험으로 바꿉니다.
